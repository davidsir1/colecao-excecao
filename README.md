# Sobre a atividade

Essa atividade foi desenvolvida utilizando o IntelliJ Idea e a versão do Java `25.0.2`. O JavaFX foi utilizado na
realização da atividade na versão `21.0.6`.

Para o desenho das telas, foi utilizado um software chamado [Scene Builder](https://gluonhq.com/products/scene-builder/)
